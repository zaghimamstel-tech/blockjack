# Блокджек

Блок-пазл с рогаликом: ставишь фигуры на поле 8×8, снимаешь линии, собираешь джокеров и проходишь 5 этажей по 3 раунда. Очки = фишки × множитель.

Движок: Godot 4.3 (GDScript, GL Compatibility). Цели: Яндекс Игры (веб), RuStore (Android), потом Google Play и App Store.

## Структура

- `core/` — правила игры без интерфейса: поле, фигуры, подсчёт очков, джокеры, состояние забега, детерминированный ГСЧ.
- `sim/` — жадный бот и симулятор баланса.
- `tests/` — тесты ядра.
- `ui/` — экран игры.

## Команды

```sh
# тесты ядра
godot --headless --path . --script res://tests/test_core.gd < /dev/null
# симулятор баланса на 200 забегов
godot --headless --path . --script res://sim/simulate.gd -- 200 < /dev/null
```

`< /dev/null` нужен, чтобы при ошибке скрипта Godot не повис в интерактивном отладчике.
